## 🛡️ I. Engineering & Clean Deployment
Following the clean static deployment principles:
1. **Validate BEFORE Process**: Ensure index.html, CNAME, and all assets exist before preparing any push or deployment.
2. **Atomicity**: When editing visual components or JavaScript code, test the site locally or ensure structural validation passes.
3. **No Dead Assets**: Verify image paths (like `LogoWhap.png` and `og-preview.png`) are correct and that the files exist in the workspace.

---

## 📈 II. Meta Ads Pixel Tracking
1. **Tracking Guardrails**:
   - Ensure the Meta Pixel Code (ID `1664455858206047`) is correctly embedded in the header of `index.html`.

---

## ✨ III. Premium Experience & UI standards
1. **Luxury Aesthetic**: All generated web interfaces must follow the "Premium Dark/Light Glassmorphism" standard:
   - **Glassmorphism**: 15px-20px blur, semi-transparent backgrounds/borders.
   - **Colors**: Curated HSL palettes. Avoid basic default browser colors.
   - **Typography**: Modern sans-serif (Inter, Montserrat, or Outfit).
2. **Micro-animations**: Interactive canvas elements (like `#hero-canvas`) and mock waveforms must render smoothly and keep CPU/memory footprint low on mobile.
